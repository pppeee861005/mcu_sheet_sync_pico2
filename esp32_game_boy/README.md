# ESP32 Game Boy (極客微型掌機系統)

## 專案簡介
這是一個基於 **ESP32-S3 DevKitC-1** 與 **0.96 吋 OLED (SSD1306)** 的獨立極客復古掌機。
完全離線運作，無須聯網，具備高儀式感開機動畫、動態主選單與四大掌機應用。

---

## 硬體接線表

| 元件 | 模組引腳 | ESP32-S3 引腳 | 說明 |
| :--- | :--- | :--- | :--- |
| **0.96" OLED (I2C)** | **GND** | **GND** | 接地 |
| | **VCC** | **3V3 或 5V** | 電源供電 |
| | **SDA** | **GPIO 21** | I2C0 數據線 |
| | **SCL** | **GPIO 22** | I2C0 時脈線 |
| **左鍵 (Button L)** | 一端 | **GPIO 18** | 內建上拉 (Next / Jump / Mode) |
| | 另一端 | **GND** | 接地 |
| **右鍵 (Button R)** | 一端 | **GPIO 4** | 內建上拉 (Enter / Action / Start) |
| | 另一端 | **GND** | 接地 |

## 內建四大應用

1. **🦖 1. DINO GAME（Chrome 小恐龍）**
   - 經典 30FPS+ 平滑跳躍物理引擎、仙人掌障礙避障與最高紀錄保存。
2. **🐱 2. CAT VOUCHER（貓咪餐券）**
   - 滿滿儀式感！3 秒長按蓄力撕票進度條、裂片動態撕裂特效、5 輪 600ms 慢嚼細嚥餵食動畫。
3. **🍅 3. POMODORO（極客番茄鐘）**
   - 專注計時器，支援 `25m Focus`、`5m Break` 與 `10s Test`，時間到全屏白閃慶祝。
4. **⏱️ 4. GEEK CLOCK（極客時鐘與碼表）**
   - 累計開機運行時間（Uptime）與精準毫秒碼表（啟動/暫停/歸零）。

---

## 操作快捷鍵
- **選單選擇**：`GPIO 18 (L)` 切換項目，`GPIO 4 (R)` 確認進入。
- **隨時返回**：在任何遊戲或應用中，**「雙鍵同按 (L + R)」** 即可返回主選單。
