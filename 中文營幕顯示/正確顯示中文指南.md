# MicroPython SSD1306 繁體中文正確顯示指南

本指南詳細記錄在 MicroPython 環境下，如何於 0.96 吋 SSD1306 OLED (128x64) 螢幕上**100% 正確、不變形、不亂碼**地渲染繁體中文字型的核心技術原理、踩坑經驗與完整工作流程。

---

## 1. 為什麼 MicroPython 預設無法顯示中文？

MicroPython 官方的 `ssd1306.py` 驅動繼承自 `framebuf.FrameBuffer`，其內建的 `oled.text(str, x, y)` 方法：
- 僅支援 **ASCII 0x20 ~ 0x7E**（8x8 點陣英數字元）。
- 當傳入中文（如 UTF-8 編碼多位元組字元）時，系統會因為索引越界或找不到字模而拋出異常，或者畫面上出現一堆問號與破圖。

---

## 2. 中文顯示破圖的兩大核心死穴（踩坑剖析）

在單片機繪製中文字型時，最常出現「看起來有字但支離破碎、反向或扭曲」的情況，原因只有兩個：

### 死穴一：取模方向錯位（Row-Major vs Column-Major）
- **Row-Major（逐行取模，本指南推薦標準）**：
  - 16x16 點陣由上到下共有 16 列（Row 0 ~ 15）。
  - 每一列有 16 個像素（由 2 個 Bytes 組成：左 8 點 + 右 8 點）。
  - 單字共 $16 \times 2 = 32\text{ bytes}$。
- **Column-Major（逐列取模）**：
  - 由左至右共有 16 欄，先取上半 8 點，再取下半 8 點。
- **如果字庫是用 Row-Major 產生，但渲染程式用 Column-Major 去讀，字元就會整片斷裂撕裂**。

### 死穴二：位元映射順序（MSB-First vs LSB-First）
- **MSB-First（高位在前）**：Byte 中的最高位元 `bit 7` 代表最左邊的像素，`bit 0` 代表最右邊。
- **LSB-First（低位在前）**：`bit 0` 代表最左邊。
- 若方向顛倒，畫出來的文字筆劃會呈現左右水平鏡像顛倒。

## 3. 正確的 16x16 點陣規範標準

本專案採用的標準點陣規範如下：

```text
每個漢字 = 16 列 (y: 0 ~ 15)，每列 2 Bytes (16 點)
共 32 Bytes
  Row 0:  [Byte 0: 左 8 點 (bit7~bit0)] [Byte 1: 右 8 點 (bit7~bit0)]
  Row 1:  [Byte 2: 左 8 點 (bit7~bit0)] [Byte 3: 右 8 點 (bit7~bit0)]
  ...
  Row 15: [Byte 30: 左 8 點]             [Byte 31: 右 8 點]
```

## 4. 自動化產生中文字型（Python PC 腳本）

不需要使用傳統容易出錯的 Windows 綠色取模軟體，直接利用電腦上的 Python 與 Pillow（PIL）函式庫，自動讀取系統字型（微軟正黑體）光柵化導出：

### 產生腳本：`generate_fonts.py`

```python
import os
from PIL import Image, ImageDraw, ImageFont

# 指定系統字型 (微軟正黑體)
font_path = 'C:\\Windows\\Fonts\\msjh.ttc'
font = ImageFont.truetype(font_path, 14)

# 填入想在螢幕上顯示的中文字
chars = ['中', '文', '螢', '幕', '顯', '示', '極', '客', '掌', '機', '上', '課', '簽', '到', '成', '功', '股', '市', '大', '盤']

output_dict = {}

for ch in chars:
    img = Image.new('1', (16, 16), 0)
    draw = ImageDraw.Draw(img)
    # 文字置中
    bbox = draw.textbbox((0, 0), ch, font=font)
    w = bbox[2] - bbox[0]
    h = bbox[3] - bbox[1]
    ox = max(0, (16 - w) // 2) - bbox[0]
    oy = max(0, (16 - h) // 2) - bbox[1]
    draw.text((ox, oy), ch, font=font, fill=1)
    
    # Row-Major: 16 行，每行 2 bytes (MSB First)
    data = []
    for y in range(16):
        b1 = 0
        b2 = 0
        for x in range(8):
            if img.getpixel((x, y)):
                b1 |= (1 << (7 - x))
        for x in range(8, 16):
            if img.getpixel((x, y)):
                b2 |= (1 << (15 - x))
        data.extend([b1, b2])
    output_dict[ch] = data

# 輸出為 MicroPython 格式的 fonts_cn.py
with open('fonts_cn.py', 'w', encoding='utf-8') as f:
    f.write("# fonts_cn.py - 繁體中文 16x16 標準點陣字型庫\nFONT_16x16 = {\n")
    for ch, d in output_dict.items():
        hex_str = ','.join(f'0x{b:02X}' for b in d)
        f.write(f'    "{ch}": bytes([{hex_str}]),\n')
    f.write("}\n")
```

## 5. MicroPython 渲染引擎實作

在 MCU 端，載入點陣庫後使用以下函式繪製：

### 渲染程式碼：`fonts_cn.py`

```python
def draw_char_16x16(oled, char, x, y, color=1):
    """
    在指定座標繪製單個 16x16 中文字
    """
    glyph = FONT_16x16.get(char)
    if not glyph:
        oled.rect(x, y, 16, 16, color)  # 找不到字時繪製方框
        return

    # Row-major 逐點點亮
    for row in range(16):
        b1 = glyph[row * 2]
        b2 = glyph[row * 2 + 1]
        for col in range(8):
            if (b1 >> (7 - col)) & 1:
                oled.pixel(x + col, y + row, color)
        for col in range(8):
            if (b2 >> (7 - col)) & 1:
                oled.pixel(x + 8 + col, y + row, color)

def draw_string_cn(oled, text, start_x, start_y, color=1):
    """
    支援繁體中文 (16x16) 與英文 (8x8) 混合排版，自動折行
    """
    cur_x = start_x
    cur_y = start_y
    for ch in text:
        if ch in FONT_16x16:
            if cur_x + 16 > 128:
                cur_x = start_x
                cur_y += 18
            draw_char_16x16(oled, ch, cur_x, cur_y, color)
            cur_x += 16
        elif ch == '\n':
            cur_x = start_x
            cur_y += 18
        else:
            # 英數字元退回 8x8 顯示 (置中微調 +4 像素)
            if cur_x + 8 > 128:
                cur_x = start_x
                cur_y += 18
            oled.text(ch, cur_x, cur_y + 4, color)
            cur_x += 8
```

## 6. 在 main.py 中的使用示範

```python
from machine import Pin, I2C
import ssd1306
from fonts_cn import draw_string_cn

# 初始化 I2C 與 0.96 吋 OLED (ESP32-S3 SDA:21, SCL:22)
i2c = I2C(0, scl=Pin(22), sda=Pin(21), freq=400000)
oled = ssd1306.SSD1306_I2C(128, 64, i2c)

oled.fill(0)

# 繪製裝飾外框
oled.rect(0, 0, 128, 64, 1)

# 顯示繁體中文標題
draw_string_cn(oled, "中文螢幕顯示", 16, 4)

# 顯示中英混排副標題
draw_string_cn(oled, "極客掌機 v1.0", 12, 28)

oled.show()
```

## 7. 常見排錯檢查清單 (Troubleshooting)

| 異常現象 | 可能原因 | 解決方式 |
| :--- | :--- | :--- |
| **文字上下撕裂、傾斜** | 取模方向與解算方向不一致（如 Row vs Column） | 確保取模程式與解模迴圈皆遵循 Row-Major（逐行 2 Bytes）。 |
| **文字左右鏡像顛倒** | 位元方向顛倒（LSB vs MSB） | 檢查 `(b1 >> (7 - col)) & 1`，確保是高位元優先（MSB First）。 |
| **文字顯示空白或黑畫面** | 忘記呼叫 `oled.show()` | 繪圖操作完成後務必執行 `oled.show()` 將顯存推送到硬體。 |
| **文字被截斷或擠在一起** | 座標累加跨距不對 | 16x16 中文字 `cur_x` 需 `+16`，8x8 英文 `cur_x` 需 `+8`。 |
