## 三、目前硬體設定

目前 `main.py` 使用 ESP32 類型設定：

| 元件 | 腳位 |
|---|---|
| OLED SDA | GPIO21 |
| OLED SCL | GPIO22 |
| 按鈕輸入 | GPIO18 |
| OLED 電源 | 3V3 |
| OLED 接地 | GND |

注意：原始開發計劃曾記載 Raspberry Pi Pico GP4/GP5，與目前程式的 GPIO21/GPIO22 不一致。接線前應以實際使用的開發板與 `main.py` 為準。
