## 三、目前硬體設定

目前 `main.py` 使用 ESP32-S3 DevKitC-1 設定。Raspberry Pi Pico／Pico 2 W 不在 v1.0 支援範圍內，除非另行修改腳位常數與測試。

| 元件 | 腳位 |
|---|---|
| OLED SDA | GPIO21 |
| OLED SCL | GPIO22 |
| 按鈕輸入 | GPIO18 |
| OLED 電源 | 3V3 |
| OLED 接地 | GND |

注意：原始 v0.1 計劃曾記載 Pico GP4/GP5；v1.0 已統一依目前實際測試的 ESP32-S3 GPIO21/GPIO22 接線。
