# 極客開發心得：Antigravity CLI (agy) 在極客掌機的完美落地與 AI 協同開發實錄

> **「這不是單純的指令代碼生成，而是一場真正將 AI Agent 嵌入邊緣物聯網（IoT）硬體開發閉環的極致體驗。」**

---

## 序言：從傳統單片機開發的痛苦說起

傳統嵌入式系統與 MicroPython 開發往往充滿了零碎而枯燥的摩擦阻力：
- 接上串口、手動找 COM 埠。
- 寫完代碼要打開 Thonny 或開終端敲 `mpremote cp` 上傳。
- 中文字體破圖？要找古老的取模軟體逐字手動點陣、轉十六進制、算對齊。
- 遇到硬體底層報錯（如 ESP32 Wi-Fi 狀態鎖死、TLS/SSL Socket 殘留 `EBUSY`）？往往要在論壇翻好幾個小時才找到線索。

在這次**「極客掌機：股票神諭機 & 雙班級課堂雲端簽到機」**的開發過程中，**Antigravity CLI (agy)** 展現了令人驚艷的自主工程能力與終端整合力，完美詮釋了什麼叫做「動動嘴，AI 幫你把軟體、韌體、字模、雲端 API 與硬體燒錄一次搞定」。

---

## 一、 驚艷亮點 1：全自主的「終端閉環」與零摩擦硬體燒錄

過去與一般 AI 對話，AI 只能把代碼打在螢幕上，開發者必須扮演「複製貼上的搬運工」。而在 `agy cli` 的協同下：
1. **自動環境感知**：`agy` 自主呼叫系統指令檢查設備，主動掃描出 `COM3`（Raspberry Pi Pico）與 `COM4`（ESP32-S3）。
2. **免手動上傳**：程式碼寫完，`agy` 直接調用 `mpremote connect COM4 cp ... + reset`，**代碼剛改完，桌上的掌機就自動重啟亮屏**。
3. **主動捕獲異常**：當螢幕卡在「Portal Open」或簽到第二個同學畫面凍結時，`agy` 主動在背景執行 REPL 抓出 `AttributeError: 'str' object has no attribute 'ljust'` 與 `OSError: 16 (EBUSY)`，**在幾秒鐘內定位問題、修復語法相容性並直接重新燒錄驗證**。這種 Debug 速度是傳統開發無法比擬的。

---

## 二、 驚艷亮點 2：攻克 16x16 繁體中文字模的「降維打擊」

要在僅有 128x64 點陣的 0.96 吋 OLED 上顯示清晰的繁體中文，一直是 MicroPython 的痛點。
`agy` 在這裡展現了跨領域工具鏈調度的強大靈活性：
- **拒絕傳統低效取模**：直接在開發機調用 Python + Pillow，動態抓取 Windows 系統內建的「微軟正黑體（`msjh.ttc`）」。
- **Row-Major 與 MSB-First 精準映射**：徹底解決字型撕裂與反向問題。
- **全自動字庫擴展**：當我們從「AIoT 實戰班（24人）」擴充到「開心農場班（16人）」時，面對包含「`繆`、`翟`、`姮`、`秩`、`赫`、`禔`、`晁`、`塭`、`祝`、`筱`、`涵`」等罕見漢字，`agy` 瞬間提煉名單、自動去重光柵化，**一秒生成 117 個專屬字模**並無縫熱更新進掌機，字體飽滿端正、清晰大方！

---

## 三、 驚艷亮點 3：深入底層的物聯網通訊防禦架構

許多人以為 AI 只能寫玩具級代碼，但這次在處理 **Google Apps Script (GAS) 302 重導向** 與 **ESP32 Wi-Fi 協定棧衝突** 時，`agy` 展現了架構師級別的底層功底：
1. **解決 `EBUSY` 連線洩漏**：
   - 抓出 MicroPython 官方 `urequests` 處理 302 重導向時未及時釋放 TLS Socket 的致命缺陷。
   - 自行架構原生 `socket` + `ssl.wrap_socket`，透過嚴格的 `s.close()` 與主動 `gc.collect()` 垃圾回收，實現連續簽到數十人依然行雲流水、絲滑零卡頓。
2. **Wi-Fi 內部狀態容錯**：
   - 增加主動 `disconnect()` 與 `active(False) -> active(True)` 的開機防禦機制，並加入離線模式優雅回退，確保硬體永遠不會死機變磚。

---

## 四、 驚艷亮點 4：優雅架構設計與多班級管理演進

從最初的單一文字顯示，到最後演變為實用度滿分的**「雙班級課堂點名神器」**：
- **開機選單 + 長按換班**：同一台掌機帶著走，開機自由切換「AIoT實戰班」或「開心農場班」；上課點名中途長按左鍵 1.8 秒發出三全音即可秒切班級。
- **雲端試算表自動分流**：GAS 端自動按班級建立獨立分頁（`AIoT實戰班_簽到記錄` / `開心農場班_簽到記錄`），完全不需要人工手動建表。
- **嚴謹的版本控制（Git Disciplined）**：每一次重大功能驗證成功（股票機儀式感跑馬燈、繁體中文指南、302重導向手冊、雙班級管理），`agy` 都會自主建立清晰乾淨的 Commit 並同步推送 GitHub，保留完整的創客演進歷程。
