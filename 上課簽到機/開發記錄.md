# 上課簽到機 開發記錄 (Changelog & Dev Logs)

本記錄詳細記載「上課簽到機 (Class Attendance Machine)」由硬體草創、版本升級、中文點陣突破至 Google 試算表雲端連線實測成功的完整演進歷程。

---

## [v2.0.1] - 2026-11-12
### 主題：連線穩定度強化與 Wi-Fi 異常狀態自動防禦
#### 完成項目：
1. **修復 ESP32 Wi-Fi 內部狀態錯誤**：
   - 解決切換 Wi-Fi 或熱點未啟動時偶發的 `OSError: Wifi Internal State Error` 異常。
   - 在連線函式中加入強制重設機制：`disconnect()` 與 `active(False) -> active(True)`，徹底防止底層狀態鎖死。
2. **優雅離線回退機制**：
   - 當所有預設 Wi-Fi（手機熱點 / 家用備援）皆逾時未連上時，不再無限期卡死，而是顯示 `離線模式` 並順利進入學生選單主畫面。
3. **完成版本控制**：
   - 提交並推送修復 Commit：`7d70ac8`。

## [v2.0] - 2026-11-12
### 主題：硬體升級 ESP32-S3 掌機、SSD1306 0.96 吋 OLED 與全繁體中文介面
#### 完成項目：
1. **硬體架構轉移**：
   - 將原本的 Pico 2 W + LCD1602 升級至 **ESP32-S3 DevKitC-1** + **0.96 吋 SSD1306 OLED (128x64)**。
   - 保留原 LCD1602 程式碼備份於 [`main_lcd1602.py`](file:///d:/練習操作區/創客/上課簽到機/main_lcd1602.py)。
2. **微軟正黑體 16x16 點陣字型庫建立**：
   - 自製向量光柵化取模工具 [`generate_fonts.py`](file:///d:/練習操作區/創客/上課簽到機/generate_fonts.py)，由 Windows 系統字型精確生成標準 Row-Major (MSB-First) 點陣字庫 [`fonts_cn.py`](file:///d:/練習操作區/創客/上課簽到機/fonts_cn.py)。
   - 支援完整繁體中文介面及學生姓名（`陳大明`、`林小美`、`王大維`、`張志豪`、`黃雅婷`、`李冠宇`、`吳家豪`、`蔡佩君`）。
3. **掌機實體雙按鍵互動**：
   - **左鍵（GPIO 18）**：一鍵循環切換下一位學生名字，伴隨蜂鳴器輕脆短嗶。
   - **右鍵（GPIO 4）**：一鍵確認並送出 Google 試算表打卡。
4. **雲端連線實測成功**：
   - 撰寫 [`google_apps_script.js`](file:///d:/練習操作區/創客/上課簽到機/google_apps_script.js) 並部署為公開 Web 應用程式。
   - 掌機發送 HTTP GET 請求直接寫入 Google 試算表，內建防重複打卡驗證。
   - 打卡成功反饋：OLED 螢幕反白閃爍、蜂鳴器雙響歡慶，並自動推進至下一位同學。
5. **完整文檔支援**：
   - 撰寫 [`google_sheet_建立指南.md`](file:///d:/練習操作區/創客/上課簽到機/google_sheet_建立指南.md)。
   - 撰寫 [`readme.md`](file:///d:/練習操作區/創客/上課簽到機/readme.md) 與硬體接線手冊。
