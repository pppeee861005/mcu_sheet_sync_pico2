# 上課簽到機 (Class Attendance Machine)

基於 **ESP32-S3 DevKitC-1** 與 **0.96 吋 SSD1306 OLED (128x64)** 的物聯網雲端課堂打卡簽到掌機系統。本版本已全方位升級為 **v2.0 繁體中文掌機版**，並完美相容 [`硬體架構.md`](file:///d:/練習操作區/創客/上課簽到機/硬體架構.md)。

---

## 1. 系統亮點與互動邏輯 (v2.0 繁體中文版)

- **16x16 繁體中文全介面**：
  - 畫面顯示：
    ```text
    ┌────────────────────────┐
    │ 學生簽到機       [1/8] │
    ├────────────────────────┤
    │  >  陳大明             │
    │ L:Next  R:Sign         │
    └────────────────────────┘
    ```
- **一鍵輪巡切換姓名（左鍵 GPIO 18）**：
  - 按下按鈕 A，發出短促「嗶」聲，依序切換繁體中文學生名單：
    `陳大明` $\rightarrow$ `林小美` $\rightarrow$ `王大維` $\rightarrow$ `張志豪` $\rightarrow$ `黃雅婷` $\rightarrow$ `李冠宇` $\rightarrow$ `吳家豪` $\rightarrow$ `蔡佩君`。
- **一鍵確認簽到（右鍵 GPIO 4）**：
  - 按下按鈕 B，立即向 Google Apps Script (GAS) Web API 發送 HTTP GET 請求進行打卡。
  - 簽到成功後：
    - OLED 畫面呈現 `簽到成功` 與學生姓名。
    - 螢幕進行**反白歡慶閃爍**。
    - 蜂鳴器（GPIO 33）與板載 LED（GPIO 2）同步**歡慶雙響**！
    - 自動切換至下一位同學，無縫接力打卡。
- **防重複打卡機制**：
  - 若同一位同學在今天已經簽過到，系統會顯示 `已經簽到`，避免重複灌水。
- **雙 Wi-Fi 自動備援**：優先連線手機熱點，家用 Wi-Fi 作為備用線路。

## 2. 硬體腳位配置（完全遵循終極極客掌機）

| 元件名稱 | 元件引腳 | ESP32-S3 腳位 | 說明 |
| :--- | :--- | :--- | :--- |
| **0.96 吋 OLED (SSD1306)** | **VCC** | **3V3** | 3.3V 電源 |
| | **GND** | **GND** | 系統接地 |
| | **SDA** | **GPIO 21** | I²C 資料線 (400kHz) |
| | **SCL** | **GPIO 22** | I²C 時脈線 |
| **按鍵 A (左鍵)** | 一端接腳位，一端接 GND | **GPIO 18** | `Pin.PULL_UP`，切換選擇下一位學生 |
| **按鍵 B (右鍵)** | 一端接腳位，一端接 GND | **GPIO 4** | `Pin.PULL_UP`，確認並送出雲端簽到 |
| **有源蜂鳴器** | 正極 (+)，負極接 GND | **GPIO 33** | `Pin.OUT`，按鍵短音與簽到歡慶雙音 |
| **板載 LED** | 內建 LED | **GPIO 2** | `Pin.OUT`，操作燈光即時反饋 |
