# AIoT LED LangChain Agent 開發紀錄

## 目前版本

**v0.1：本機版 — 已完成**

## v0.1 完成內容

- 建立 Python LangChain Agent 專案架構。
- 定義 LED 專用 Agent 行為規則。
- 整合既有 LED Skill、MCP 與 HTTP API 設計。
- 支援開燈、關燈與查詢狀態。
- 限制 Agent 只能執行 LED 白名單操作。
- 定義 API 失敗與不支援指令的處理方式。
- 建立 v0.1 至 v1.0 的開發路線。

## 已知整合元件

```text
Python LangChain Agent
        ↓
LED Tool／MCP
        ↓
既有 Vercel HTTP API
        ↓
Pico 2 W + WS2812 LED
```
