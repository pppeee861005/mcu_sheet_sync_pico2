## 開發方式

本版本使用手機上的 Codex Remote，遠端連線至電腦上的 Codex Desktop，並在指定專案中完成操作。

```text
手機 Codex
    ↓ Remote
PC Codex Desktop
    ↓
aiot led 專案
    ↓
AIoT LED Control Skill
    ↓
HTTP API
    ↓
Pico 2 W + WS2812 LED
```

## 已完成項目

- 手機 Codex 與 PC Codex Remote 配對成功。
- 成功使用指定的 `iot led` 專案。
- 成功執行 LED 開燈指令。
- API 回傳 `HTTP 200` 與 `LED_ON`。
- 成功確認 LED 原本為開燈狀態。
- 成功執行 LED 關燈指令。
- API 回傳 `HTTP 200` 與 `LED_OFF`。
- 確認任務完成。
