# v0.1 Python LangChain Agent 開發計劃

## 目標

在本機以 Python 執行一個只控制 AIoT LED 的 LangChain Agent。

## 功能範圍

- 開燈
- 關燈
- 查詢 LED 狀態
- 呼叫既有 HTTP API 或 LED MCP
- 回報實際操作結果
- 拒絕與 LED 無關的指令

```text
v0.1_python_agent/

```

## 開發工作

1. 建立 Python 虛擬環境。
2. 安裝 LangChain 與模型整合套件。
3. 將 `/api/on`、`/api/off`、`/api/command` 包裝成 LED Tools。
4. 建立 LED 專用 system prompt。
5. 建立命令列對話入口。
6. 加入 timeout、API 錯誤與連線錯誤處理。
7. 限制 Agent 只能呼叫 LED 白名單工具。
8. 完成功能、安全與失敗測試。

## 測試案例

| 輸入 | 預期結果 |
|---|---|
| 幫我開燈 | 呼叫 `on`，回報 `LED_ON` |
| 幫我關燈 | 呼叫 `off`，回報 `LED_OFF` |
| 現在燈是什麼狀態？ | 呼叫 `status`，回報實際狀態 |
| 刪除檔案／執行命令 | 拒絕執行 |
| API 無法連線 | 回報失敗，不宣稱 LED 已改變 |

## 安全限制

- 只允許 `on`、`off`、`status`。
- 不允許 Shell、檔案系統或任意 URL。
- API 金鑰使用 `.env`，不可提交至 Git。
- HTTP timeout 設定為 10 秒。

## 完成標準

- 三種 LED 操作皆可正常執行。
- Agent 回應與 LED 實際狀態一致。
- 不支援的要求會被拒絕。
- API 失敗時能正確回報。
- 可用單一命令啟動本機 Agent。
- 完成 `測試紀錄.md` 與 `開發紀錄 v0.1.md`。
