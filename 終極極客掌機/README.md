# 🎮 SkyDeck OS 終極極客掌機 (純離線全功能掌機)

專為 ESP32 / ESP32-S3 設計的 MicroPython 輕量級離線掌上系統。內建 4 大經典極客應用、流暢 UI 轉場、專屬蜂鳴器按鍵音效與板載 LED 燈效反饋。

---

## 📌 4 大核心應用

1. **小恐龍跳躍 (Chrome Dino Game)**
   - 經典離線小恐龍躲仙人掌遊戲，支援實時跳躍物理模擬與歷史最高分紀錄。
   - 跳躍與撞擊皆有蜂鳴器音效及 LED 閃爍提示。
2. **貓咪餐券 (Cat Voucher - 極致儀式感版)**
   - 實體模擬按鍵長按 3 秒蓄力撕票動畫。
   - 包含多幀慢速進食與滿足表情動畫（`nyam!`, `crunch!`, `satisfied!`）。
3. **極客番茄鐘 (Pomodoro Focus)**
   - 支援 25 分鐘專注模式、5 分鐘短暫休息、10 秒快速展示模式。
   - 倒數結束具備 OLED 白閃畫面、急促鬧鈴與板載 LED 爆閃提醒。
4. **極客時鐘與碼表 (Geek Clock & Stopwatch)**
   - 系統累積運行時間（Uptime）即時監控。
   - 毫秒級精度碼表，支援隨時暫停與一鍵歸零。

## 🔌 硬體接線對照表 (Pinout)

硬體核心基於 **ESP32 / ESP32-S3** 開發板，搭配 **0.96 吋 I2C OLED (SSD1306)**、雙按鈕與蜂鳴器：

| 元件名稱 | 模組引腳 | ESP32 GPIO 腳位 | 說明 / 注意事項 |
| :--- | :--- | :--- | :--- |
| **0.96" OLED (SSD1306)** | SDA | **GPIO 21** | I2C 資料線 (400kHz) |
| | SCL | **GPIO 22** | I2C 時脈線 |
| | VCC | **3.3V** | 請接 3.3V 供電 |
| | GND | **GND** | 接地 |
| **左鍵 (Button Left)** | 端子 A | **GPIO 18** | 內建上拉（PULL_UP），按下接 GND |
| | 端子 B | **GND** | |
| **右鍵 (Button Right)** | 端子 A | **GPIO 4** | 內建上拉（PULL_UP），按下接 GND |
| | 端子 B | **GND** | |
| **蜂鳴器 (Buzzer)** | 正極 (+) | **GPIO 33** | 有源蜂鳴器訊號驅動 |
| | 負極 (-) | **GND** | |
| **板載 LED** | 內建 | **GPIO 2** | 系統狀態與鬧鈴爆閃指示 |

## 🕹️ 按鍵操作說明

- **主選單中**：
  - **左鍵 (L)**：切換下一個應用程式
  - **右鍵 (R)**：確認進入該應用
- **任何應用中（隨時返回）**：
  - **同時按住「左鍵 + 右鍵」**：立即安全退出並返回 SkyDeck 主選單
- **各應用專屬操作**：
  - **小恐龍**：左鍵或右鍵均可觸發起跳；Game Over 後單按任意鍵重新開始
  - **貓咪餐券**：按住右鍵不放約 3 秒完成撕票儀式
  - **番茄鐘**：未運行時左鍵切換時長模式；右鍵開始/暫停；運行中左鍵一鍵重設
  - **碼表**：右鍵開始/暫停計時；左鍵歸零

## 🚀 燒錄與部署方法

在專案目錄下使用 MicroPython 官方命令列工具 `mpremote` 快速燒錄：

```powershell
# 1. 偵測裝置連接埠 (例如 COM4)
python -m mpremote devs

# 2. 上傳驅動庫與主程式並重啟開發板
python -m mpremote connect COM4 cp ssd1306.py :ssd1306.py
python -m mpremote connect COM4 cp main.py :main.py + reset
```
