# 操作手冊與燒錄指南 (Step-by-Step SOP)

本指南引導您從「Google 雲端設定」到「ESP32-S3 實體板燒錄與測試」，請依照以下四個步驟依序操作。

---

## 步驟一：Google 試算表與 GAS 雲端設定 (約 3 分鐘)

### 1. 建立試算表
1. 打開瀏覽器進入 [Google Drive](https://drive.google.com/)。
2. 點選 **「新增」 -> 「Google 試算表」**。
3. 將試算表命名為：`農夫機器人_MCU記錄表`。

### 2. 貼入 Google Apps Script 程式碼
1. 在試算表上方選單點選 **「擴充功能 (Extensions)」 -> 「Apps Script」**。
2. 刪除編輯器內原本預設的程式碼。
3. 打開專案中的 [`google_apps_script.js`](file:///D:/練習操作區/創客/mcu_sheet_sync/google_apps_script.js)，**全選複製並貼上**。
4. 點選上方的磁碟圖示 **「儲存專案 (Ctrl + S)」**。

### 3. 發布為公開 Web 應用程式 (關鍵步驟)
1. 點選右上角的藍色按鈕 **「部署 (Deploy)」 -> 「新增部署作業 (New deployment)」**。
2. 點選左側齒輪圖示，選擇 **「網頁應用程式 (Web app)」**：
   - **說明**：`MCU Sheet API`
   - **執行身分**：`我 (Me / 您的 Google 帳號)`
   - **誰可以存取**：**`任何人 (Anyone)`** *(務必選「任何人」，否則 MCU 無法免認證寫入)*
3. 點選 **「部署」**。
4. 初次部署時會跳出授權視窗：
   - 點選 **「審查權限 (Review Permissions)」**。
   - 選擇您的 Google 帳號。
   - 若出現「Google 尚未驗證這個應用程式」，點選左下方 **「進階 (Advanced)」 -> 「前往（不安全）」**。
   - 點選 **「允許 (Allow)」**。
5. 部署完成後，複製畫面上顯示的 **「網頁應用程式網址 (Web App URL)」**（網址結尾為 `/exec`）。

## 步驟二：更新 MCU 程式中的 API 網址

1. 打開本目錄下的 [`main.py`](file:///D:/練習操作區/創客/mcu_sheet_sync/main.py)。
2. 找到第 31 行：
   ```python
   GAS_URL = "https://script.google.com/macros/s/AKfycbxYOUR_DEPLOYMENT_ID/exec"
   ```
3. 將其替換為您在步驟一複製的真實網址並存檔。

## 步驟三：使用 mpremote 燒錄到 ESP32-S3

1. 使用 USB 傳輸線將 ESP32-S3 開發板接上電腦。
2. 在 VS Code 或 PowerShell 開啟終端機，切換到本專案目錄：
   ```powershell
   cd 'd:\練習操作區\創客\mcu_sheet_sync'
   ```
3. **檢查裝置連接埠**：
   ```powershell
   mpremote devs
   ```
   *(記錄顯示的 COM 埠號，例如 `COM4`)*

4. **將驅動與主程式上傳至板子**：
   ```powershell
   # 替換 COM4 為您實際偵測到的 COM 埠
   mpremote connect COM4 cp ssd1306.py :ssd1306.py
   mpremote connect COM4 cp main.py :main.py
   ```

5. **軟體重開機板子**：
   ```powershell
   mpremote connect COM4 reset
   ```

## 步驟四：實體測試與驗證

1. **開機自檢**：
   - ESP32-S3 通電開機。
   - OLED 顯示開機文字，接著依序嘗試 Wi-Fi（家用 `egg5630` 或手機熱點 `Redmi 13C`）。
   - 連線成功後，OLED 顯示配發的 IP 位址，接著進入 **`[ Standby ]` 待機畫面**。
2. **按鍵觸發寫入**：
   - 按下接在 `GPIO 18` 的實體按鈕。
   - OLED 顯示 **`Sending Data...`**。
   - 資料送達後，OLED 顯示 **`Upload Success!`** 並維持 2 秒。
   - 回到瀏覽器查看 Google 試算表，會看到即時追加了一列新資料！
   - OLED 自動恢復 **`[ Standby ]`**，等待下一次按鍵觸發。

## 常見問題排查 (FAQ)

- **Q1: OLED 完全沒有畫面？**
  - 請檢查接線：SDA 是否接在 `GPIO 21`、SCL 是否接在 `GPIO 22`、供電是否為 `3V3`。
- **Q2: Wi-Fi 連線逾時 (WiFi Error)？**
  - 請確認家用 Wi-Fi 或手機熱點已開啟，且頻段為 **2.4GHz**。
- **Q3: OLED 顯示 Upload Failed？**
  - 請確認 `GAS_URL` 網址是否完整複製（結尾是否有 `/exec`）。
  - 請確認 GAS 部署時「誰可以存取」是否確實設定為「任何人 (Anyone)」。
