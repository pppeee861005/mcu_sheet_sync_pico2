# 任務需求規格書 (mcu_sheet_sync)

## 1. 專案目標與任務說明
微控制器（ESP32-S3）開機通電後，自動依序嘗試連線 Wi-Fi，連線成功後進入待機狀態並在 OLED 顯示「待機中」。當使用者按下實體按鍵時，MCU 發送 HTTP 請求至 Google Apps Script (GAS)，將數據自動寫入 Google 試算表（Google Sheets），並在 OLED 顯示寫入結果後自動返回待機狀態。

---

## 2. 系統行為流程 (State Flow)

```text
[ 通電開機 ]
    │
    ▼
[ Wi-Fi 自動切換連線 ] ──→ 先嘗試「家用 egg5630」，若逾時自動切換「手機 Redmi 13C」
    │
    ▼
[ 連線成功 ] ──→ OLED 顯示 IP 位址與「待機中 (Standby)」
    │
    ▼
[ 待機監聽迴圈 ] ──→ 監聽 GPIO 18 按鍵（包含軟體防彈跳）
    │
    │ (使用者按下按鍵)
    ▼
[ 觸發上傳 ] ──→ OLED 顯示「上傳中... (Sending...)」
    │
    ▼
[ GAS HTTP POST ] ──→ 發送 JSON 數據至 Google Apps Script Web App
    │
    ▼
[ 狀態回饋 ] ──→ OLED 顯示「寫入成功 (OK!)」或「錯誤提示」，停留 2 秒
    │
    ▼
[ 返回待機 ] ──→ 重新顯示「待機中 (Standby)」，等待下一次按鍵
```

---

## 3. Wi-Fi 自動切換規則 (Auto Fallback)

MCU 內部設定 Wi-Fi 候選清單，開機時按優先序自動輪詢嘗試：
1. **第一優先**：家用 Wi-Fi (`egg5630` / `27985630`)，逾時等待約 8 秒。
2. **第二備援**：手機熱點 (`Redmi 13C` / `chdmchkcrdfd7e8`)，若第一優先失敗則自動切換。

---

## 4. 硬體腳位配置

| 週邊元件 | 腳位名稱 | ESP32-S3 腳位 | 說明 |
| :--- | :--- | :--- | :--- |
| **SSD1306 OLED** | SDA | **GPIO 21** | I²C 資料線 (I2C0, 400kHz) |
| | SCL | **GPIO 22** | I²C 時脈線 |
| | VCC / GND | **3V3 / GND** | 3.3V 供電 |
| **實體按鍵** | 輸入端 | **GPIO 18** | 內部上拉電阻 (`Pin.IN, Pin.PULL_UP`)，按下為低電位 0 |
| | 接地端 | **GND** | 共同接地 |

---

## 5. Google 試算表寫入規格

- **通訊方式**：Google Apps Script (GAS) Web App (HTTP POST)
- **傳送格式 (JSON Payload)**：
  ```json
  {
    "device": "ESP32-S3",
    "event": "Button_Press",
    "press_count": 1,
    "status": "Triggered"
  }
  ```
- **試算表寫入欄位**：
  `[ 伺服器時間戳記, 裝置名稱, 事件類型, 觸發累計次數, 備註 ]`
