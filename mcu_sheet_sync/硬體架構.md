# 硬體架構與接線規範 (mcu_sheet_sync)

本專案硬體接線參考自 [`Pico 小恐龍 Dino Game`](file:///D:/練習操作區/創客/Pico%20小恐龍%20Dino%20Game) 的成熟配置，採用 **ESP32-S3 DevKitC-1** 作為核心主控板，搭配 **0.96 吋 SSD1306 OLED 螢幕** 提供狀態回饋，並以 **實體按鈕** 提供互動觸發。

---

## 1. 核心硬體資訊

- **核心主控板**：ESP32-S3 DevKitC-1
- **韌體版本**：MicroPython
- **燒錄/串列通訊**：USB-to-UART（`mpremote`，常用 COM 埠：`COM3` 或 `COM4`）
- **無線通訊**：內建 2.4GHz Wi-Fi（802.11 b/g/n）

---

## 2. 實體元件與接線腳位表 (Pinout Table)

| 週邊元件 | 元件引腳 | ESP32-S3 腳位 | 訊號/功能說明 |
| :--- | :--- | :--- | :--- |
| **0.96 吋 OLED 螢幕**<br>(SSD1306 128×64) | **VCC** | **3V3** | 3.3V 電源供應 |
| | **GND** | **GND** | 系統共地 |
| | **SDA** | **GPIO 21** | I²C 資料線 (I2C ID: 0, 頻率: 400kHz) |
| | **SCL / SCK** | **GPIO 22** | I²C 時脈線 |
| **實體按鈕**<br>(可作為手動寫入觸發) | 一端 | **GPIO 18** | 內部上拉電阻 (`Pin.IN, Pin.PULL_UP`) |
| | 另一端 | **GND** | 按下為低電位（0），放開為高電位（1） |

## 4. MicroPython 硬體初始化程式範本

```python
from machine import Pin, I2C
import ssd1306

# 腳位常數定義
SDA_PIN = 21
SCL_PIN = 22
BUTTON_PIN = 18

# OLED 規格
WIDTH = 128
HEIGHT = 64

# 1. 初始化 I2C 與 OLED 螢幕
i2c = I2C(0, scl=Pin(SCL_PIN), sda=Pin(SDA_PIN), freq=400000)
oled = ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c)

# 2. 初始化按鈕 (啟用內部上拉)
button = Pin(BUTTON_PIN, Pin.IN, Pin.PULL_UP)

# 3. 畫面顯示測試
def show_status(line1, line2="", line3=""):
    oled.fill(0)
    oled.text(line1, 0, 0)
    if line2:
        oled.text(line2, 0, 20)
    if line3:
        oled.text(line3, 0, 40)
    oled.show()
```

## 5. 在 Sheet 通訊中的應用機制

1. **OLED 即時狀態面板**：
   - 開機階段：顯示 `WiFi: Connecting...`
   - 連線成功：顯示 `IP: 192.168.x.x`
   - 上傳資料：顯示 `Sheet: Uploading...` -> `Sheet: OK!`
2. **實體按鈕互動機制**：
   - **自動觸發**：MCU 開機通電後自動上傳一筆開機記錄。
   - **手動觸發**：使用者隨時按下按鈕（GPIO 18），即刻採樣並向 Google Sheet 新增一筆記錄。
