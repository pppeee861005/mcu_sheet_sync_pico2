### Phase 3：MCU 實體板燒錄與測試 (Board-level Smoke Test)
- [ ] **連接板子**：USB 接上 ESP32-S3 開發板
- [ ] **檢查 COM 埠**：執行 `mpremote devs` 確認識別（例如 COM4）
- [ ] **上傳檔案**：
  ```powershell
  mpremote connect COMx cp ssd1306.py :ssd1306.py
  mpremote connect COMx cp main.py :main.py
  ```
- [ ] **通電開機測試**：
  - [ ] 螢幕開機顯示正常
  - [ ] Wi-Fi 自動連線成功（測試家用 Wi-Fi 或手機熱點）
  - [ ] 螢幕顯示 IP 與 `[ Standby ]` 待機畫面
- [ ] **按鍵上傳測試**：
  - [ ] 按下 GPIO 18 按鈕，螢幕顯示 `Sending Data...`
  - [ ] Google 試算表即時新增一筆記錄
  - [ ] 螢幕顯示 `Upload Success!` 停留 2 秒後重返 `[ Standby ]`
  - [ ] 連續按鍵測試（防彈跳正常、次數累計正確）
