## 2. 細部工作項目清單 (Task Breakdown)

### 階段一：環境配置與雲端後端 (M1)
- [x] **T1.1 金鑰整合**：在 `config.py` 中解析 `.env` 動態載入 `GOOGLE_API_KEY`，具備安全防護與預設備援。
- [x] **T1.2 試算表欄位規劃**：於 Google Sheet 定義 `FarmData`（農田環境來源）與 `FarmLogs`（AI決策日誌）。
- [x] **T1.3 GAS 讀取 API**：在 `google_apps_script.js` 實作 `action=get_farm_data`，回傳空氣濕度、氣溫、土壤乾度、電解質、降雨預報。
- [x] **T1.4 GAS 日誌 API**：支援接收 AI 決策結果 (`action=log_ai_decision`) 並自動寫入 `FarmLogs` 分頁。

### 階段二：Gemini 2.5 Flash 推理核心 (M2)
- [x] **T2.1 原生 HTTPS POST 封裝**：利用 MicroPython 原生 `socket` + `ssl` 實作 `call_gemini_flash()`，直接調用 Google Gemini REST API。
- [x] **T2.2 Prompt Engineering**：
  - 設定農業灌溉專家 System Prompt，針對 5 大特徵進行二元決策。
  - 強制輸出格式為純 JSON：`{"water": true/false, "decision": "WATER/NO WATER", "reason": "16_char_max"}`。
- [x] **T2.3 JSON 安全解析與容錯**：實作 `parse_gemini_json()` 提取 JSON 字典，過濾 Markdown 標籤，並內建離線 Fallback 規則。

### 階段三：韌體 UI 與前置檢查 (M3)
- [x] **T3.1 主選單擴充**：修改 `main.py` 的 `SYSTEMS` 清單，新增 `{"name": "4.AI Agri", "desc": "Irrigate Inference"}`。
- [x] **T3.2 農田數據前置檢查**：
  - 若試算表無資料或無感測數值，LCD 螢幕第二行直接打印：`No_data`，並安全退出推理流程。
- [x] **T3.3 狀態動態顯示**：
  - 連線時：`Reading Sheet...` / `Checking Data...`
  - 推理中：`Farm Data OK!` / `AI Thinking...`
  - 完成時：第一行 `>> WATER NOW <<` / 第二行簡短英文原由（≤ 16 字元，不換行裁切）。

### 階段四：雲端日誌回寫與整合驗證 (M4)
- [x] **T4.1 日誌回寫實作**：將當次決策、理由與各項環境數據透過 `safe_gas_request` 回傳至 Google Sheet。
- [x] **T4.2 離線與超時防護**：網路中斷或 API 逾時自動降級為土壤乾度規則並提示。
- [x] **T4.3 記憶體與垃圾回收驗證**：請求前後執行 `gc.collect()`；已通過 Python 語法編譯檢查 (`py_compile` exit code 0)。
