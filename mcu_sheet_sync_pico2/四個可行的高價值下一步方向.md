# 農業機器人 v1.0：四個可行的高價值下一步方向

**專案現狀**：已完成 Pico 2 W + Google Sheet (E 欄) + Gemini 3.5 Flash + LCD1602 的端到端雙向推理系統，並完成 GitHub 釋出與安全加固。  
為進一步將本專案推進至現場實用化與全面智慧化，本文件規劃了四個不同維度的演進方向。

---

## 方向一：實體繼電器與抽水馬達控制（硬體動作閉環）

### 1. 核心目標
將 AI 的決策從「螢幕顯示 `>> WATER NOW <<`」真正推進為「驅動硬體水閥或沉水幫浦」。

```mermaid
flowchart LR
    A["Gemini 決策: WATER"] --> B["Pico 2 W (GP15 輸出 HIGH)"]
    B --> C["5V 繼電器 / MOSFET 模組"]
    C --> D["抽水馬達運轉 5~10 秒"]
    D --> E["自動關閉並寫入日誌"]
```

### 2. 硬體接線規劃
| 元件 | 模組腳位 | Pico 2 W 腳位 | 備註 |
| :--- | :--- | :--- | :--- |
| **5V 繼電器模組 (Relay)** | **VCC** | **VBUS** (5V) | 繼電器線圈需 5V 驅動 |
| | **GND** | **GND** | 共地 |
| | **IN** | **GP15** | 數位輸出控制信號 (High/Low) |
| **微型沉水幫浦 (5V)** | 正極 | 繼電器 NO (常開端) | 透過外部 5V 或 USB 供電 |
| | 負極 | 電源 GND | |

### 3. 實作重點
- 在 `main.py` 加入安全定時關閉機制，避免水閥長開造成農田澇災。
- 加入急停防呆（例如按鈕強制中斷供水）。

## 方向二：實體感測器現地採集（邊緣數據直讀）

### 1. 核心目標
告別目前試算表手動輸入的模擬數據，改由現地感測器自主感知農田真實環境。

### 2. 推薦元件配置
1. **電容式土壤濕度感測器 (Capacitive Soil Moisture Sensor v1.2)**：
   - 避免傳統電極式容易生鏽氧化問題。
   - 訊號線接至 Pico 2 W 的 **GP26 (ADC0)** 讀取類比電壓。
2. **DHT11 / DHT22 溫濕度感測器**：
   - 讀取環境空氣溫度與空氣濕度，訊號線接至 **GP2**。
3. **光照度感測器 (光敏電阻 / BH1750)**：
   - 輔助判斷目前是正午強光還是夜間，避免高溫烈日下澆水造成作物根部熱水燙傷。

### 3. 資料流架構
```
[感測器現地採集] ➔ [Pico 2 W 整理] ➔ [自動寫入 Sheet E 欄] ➔ [Gemini AI 推理]
```

## 方向三：定時排程自動巡檢（完全自主免人工操作）

### 1. 核心目標
取消手動按鍵觸發，讓機器人每隔固定時間自動「甦醒巡檢 ➔ 推理 ➔ 灌溉 ➔ 休眠」。

### 2. 技術規格
- **巡檢週期**：設定每 30 分鐘或 1 小時執行一次巡檢循環。
- **低功耗與螢幕保護**：
  - 平時關閉 LCD1602 背光（`lcd.hal_backlight_off()`）以延長壽命並節約能源。
  - 巡檢啟動時喚醒背光，展示推理過程，完成後 30 秒自動休眠。
- **看門狗計時器 (Watchdog Timer - WDT)**：
  - 啟用 MicroPython 內建 `machine.WDT`，防止在野外惡劣網路下網路卡死時無人重啟。

## 方向四：雲端 Line Bot / 手機通知（遠端戰情報告）

### 1. 核心目標
當農業機器人做出澆水決策或遇到異常（如離線保底 `Offline Rule`）時，主動通報農民手機。

### 2. 架構實施
善用現有的 **Google Apps Script (GAS)** 後端，不需在 Pico 2 W 增加繁重通訊協定負擔：

```
[Pico 2 W 回寫 FarmLogs]
         │ (POST)
         ▼
[Google Apps Script] ─── (決策為 WATER 或 Offline Rule?)
         │ 是
         ▼
[呼叫 LINE Messaging API / Telegram Bot / Gmail]
         │
         ▼
[農夫手機收到推播通知]
```

### 3. 推播範例內容
> 🌱 **【農業機器人通報】**  
> • 時間：2026-11-04 20:30  
> • 狀態：**已啟動自動灌溉** 💧  
> • AI 原因：`Very dry soil` (乾度 80%, 氣溫 25.5°C)  
> • 預計供水：8 秒鐘
