# 農業機器人 v1.0：硬體配置與接線指南

本文件詳細記錄 **Raspberry Pi Pico 2 W** 與周邊模組（LCD1602、實體按鈕、未來擴充繼電器與感測器）之完整硬體配置、腳位映射表、電氣規格與組裝注意事項。

---

## 1. 核心控制器規格：Raspberry Pi Pico 2 W

* **處理核心**：雙核心 Arm Cortex-M33 / 雙 Hazard3 RISC-V @ 150MHz
* **SRAM**：520 KB
* **快閃記憶體 (Flash)**：4 MB
* **無線連線**：2.4GHz 802.11n Wi-Fi + Bluetooth 5.2
* **邏輯工作電壓**：**3.3V**（所有 GPIO 容許電壓為 3.3V，不可直接輸入 5V）
* **供電來源**：Micro-USB 5V 經由 `VBUS` (Pin 40) 輸入

---

## 2. 目前已啟用之硬體接線對照表 (v1.0 基礎配置)

```
        +-----------------------------------------+
        |          Raspberry Pi Pico 2 W          |
        |                                         |
        |  [GP0] Pin 1  --------> LCD1602 SDA     |
        |  [GP1] Pin 2  --------> LCD1602 SCL     |
        |  [GND] Pin 38 --------> LCD1602 GND     |
        | [VBUS] Pin 40 --------> LCD1602 VCC(5V) |
        |                                         |
        | [GP14] Pin 19 --------> 按鈕 1 (Left)   |
        |  [GND] Pin 18 --------> 按鈕 1 另一端   |
        | [GP16] Pin 21 --------> 按鈕 2 (Right)  |
        |  [GND] Pin 23 --------> 按鈕 2 另一端   |
```

## 3. LCD1602 (PCF8574) 模組調校與電氣特徵

1. **I2C 預設通訊位址**：
   - 一般 PCF8574T 晶片位址為 `0x27`。
   - 部分 PCF8574AT 晶片位址為 `0x3F`。
   - 韌體在 `main.py` 開機時會自動呼叫 `i2c.scan()` 自動探測位址，免手動修改。
2. **對比度調整（防白屏/方塊）**：
   - 模組背面有一顆藍色方形精密可變電阻。
   - 若通電後看到整排黑方塊或文字過淡看不清，請使用十字螺絲起子微調旋鈕，直到字元邊緣清晰銳利為止。
3. **背光控制**：
   - 模組背面有一組黑色跳線帽（Jumper），拔下會完全切斷背光。本專案請維持插上狀態，由 MicroPython 韌體軟體控制背光開關與閃爍儀式。

| | **GND** | **Pin 38 (GND)** | GND | 共地 |

## 5. 電源與接地安全守則 (Best Practices)

1. **嚴禁將 5V (VBUS) 接入 Pico 2 W 的 GPIO**：
   - Pico 2 W 的所有 GPIO 容忍電壓上限為 **3.6V**。
   - 感測器的輸出訊號如果大於 3.3V，必須使用電阻分壓或電位轉換晶片（Logic Level Shifter）。
2. **共地原則 (Common Ground)**：
   - 所有感測器、外接電源、繼電器與 Pico 2 W 的 GND 必須互相連接在一起，以維持參考電位的一致性，防止訊號誤判或通訊雜訊。
3. **電感性負載防護（抽水馬達）**：
   - 沉水馬達或電磁水閥運轉與斷開瞬間會產生反向電動勢（Flyback Voltage）。
   - 請選用**自帶光耦隔離 (Optocoupler)** 與反向續流二極體的標準繼電器模組，並建議馬達使用獨立電源供電，避免干擾 Pico 2 W 造成 Wi-Fi 斷線或重開機。
