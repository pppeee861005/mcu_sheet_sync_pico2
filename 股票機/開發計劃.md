# 股票機：台股大盤指數即時監控機 開發計劃書

本計劃書規範專案開發流程、硬體腳位定義、軟體爬蟲架構（依據 `stocks.py`）、雲端中繼設計與 MicroPython 韌體驗收標準。

---

## 一、 專案定位與需求概述

* **專案名稱**：股票機 (Pico 2 W 台股大盤看板)
* **核心功能**：透過網路定時爬取台灣證券交易所 (TWSE) 發行量加權股價指數（大盤 TAIEX），於 LCD1602 螢幕即時顯示當日指數與漲跌點數。
* **主要硬體**：Raspberry Pi Pico 2 W + LCD1602 (PCF8574 I2C 介面)。
* **技術架構**：
  - **資料來源**：TWSE FMTQIK 盤後/即時資料 API（源自 `stocks.py`）。
  - **雲端中繼**：Google Apps Script (GAS) 負責資料清洗、轉拋與快取，減輕 MCU 負擔。
  - **韌體端**：MicroPython 撰寫，具備多 Wi-Fi 自動容錯與按鈕中斷刷新機制。

## 三、 硬體介面與接線規範 (同 mcu_sheet_sync_pico2)

| 元件名稱 | 模組腳位 | Pico 2 W 實體腳位 | 功能定義 | 備註說明 |
| :--- | :--- | :--- | :--- | :--- |
| **LCD1602 螢幕**<br>(PCF8574 I2C) | **GND** | **Pin 38 (GND)** | 系統共地 | 確保地電位一致 |
| | **VCC** | **Pin 40 (VBUS)** | **5V 電源輸入** | **重要**：3.3V 會導致對比不足白屏，須接 5V |
| | **SDA** | **Pin 1 (GP0)** | I2C0 資料線 | 內部上拉 / 通訊頻率 100kHz |
| | **SCL** | **Pin 2 (GP1)** | I2C0 時脈線 | I2C0 預設匯流排 |
| **按鍵 1 (SW1)** | 訊號端 | **Pin 19 (GP14)** | 數位輸入 (IN) | 手動強制刷新 (內建上拉 `Pin.PULL_UP`) |
| | 參考端 | **Pin 18 (GND)** | 參考地 | 按下為 Low 電位觸發 |
| **按鍵 2 (SW2)** | 訊號端 | **Pin 21 (GP16)** | 數位輸入 (IN) | LCD 背光開關 / 備用功能 |
| | 參考端 | **Pin 23 (GND)** | 參考地 | 按下為 Low 電位觸發 |

## 四、 軟體開發工作拆解 (WBS)

### 階段 1：雲端爬蟲與中繼 API 開發 (GAS)
* **參考程式**：`stocks.py` 函式 `index_info()`。
* **實作檔案**：`google_apps_script.js`。
* **職責**：
  1. 向證交所發送查詢請求。
  2. 若遇假日無開盤資料，自動往前取得最近一個交易日收盤行情。
  3. 產出標準 JSON：
     ```json
     {
       "status": "success",
       "date": "113/11/11",
       "index": "23,522.53",
       "raw_index": 23522.53,
       "change": "+148.87",
       "direction": "UP",
       "timestamp": "2026-11-11 18:55:00"
     }
     ```
  4. 部署為免驗證之 Web App (Exec URL)。

### 階段 2：Pico 2 W 韌體核心開發 (`main.py`)
* **模組架構**：
  - `config.py`：Wi-Fi SSID 清單與 GAS Web App URL。
  - `lcd_api.py` / `pico_i2c_lcd.py`：LCD 驅動與自訂 LCD 點陣字元（▲ 漲、▼ 跌）。
  - `main.py`：主控制狀態機。
* **主要功能流程**：
  1. 開機 I2C 探測與 LCD 初始化。
  2. 依序嘗試連線清單中的 Wi-Fi（手機熱點優先，家用 Wi-Fi 備援）。
  3. 連線成功後向 GAS 請求即時行情。
  4. 渲染至 LCD1602，並進入定時省電等待循環。
  5. 支援 GP14 按鍵中斷，隨按隨刷新。

### 階段 3：異常防護與健壯性 (Robustness)
* **網路斷線重連**：若 Wi-Fi 斷線或請求超時，LCD 提示 `WiFi Reconnecting`，自動重試不當機。
* **開休市判斷**：收盤與假日維持顯示最後一筆有效行情，並以狀態標記避免無效高頻請求。
