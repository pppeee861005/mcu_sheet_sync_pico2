# 股票機 開發記錄 (Changelog & Dev Logs)

本記錄詳細記載「股票機 (Pico 2 W 大盤指數監控機)」的架構演進、功能增強與各版本迭代記錄。

---

## [v1.01] - 2026-11-12 (已實作完成)
### 主題：神諭降臨（神秘儀式感擴充）
#### 完成功能與驗證：
1. **3 秒神聖沙漏滴落與時鐘倒數動畫 (`hourglass_countdown_animation`)**：
   - 擴充 3 組 5x8 自訂點陣符號：`ICON_SAND_1`（滿沙）、`ICON_SAND_2`（流沙中）、`ICON_SAND_3`（沙漏流盡）。
   - 在雲端天機獲取完畢與大盤揭曉之間，插入 3 秒儀式沙漏倒數（`3s` $\rightarrow$ `2s` $\rightarrow$ `1s` $\rightarrow$ `DESTINY CAST / READY`），動態幀每 0.5 秒切換流沙狀態與光點。
2. **雙行同步慢速跑馬燈 (`marquee_display_dual`)**：
   - 第一行（TAIEX 指數）與第二行（漲跌點數與祝福）皆納入走馬燈展示。
   - 滾動速度放慢 70%（每格 0.45s），步調極度沉著莊嚴。
   - 跑馬燈播放完畢後，在螢幕靜態駐留 4 秒展示精簡結果，隨後返回神壇。
3. **單次抓取節能機制 (Single Fetch Cache)**：
   - 全域快取 `CACHED_DATA`，開機後整個運行過程僅向 GAS 發出一次 HTTP 請求獲取大盤天機，後續按鍵召喚直接調用快取，避免重複請求 Google 試算表造成負載。
4. **修復 LCD 驅動相容問題**：
   - 在 [`pico_i2c_lcd.py`](file:///d:/練習操作區/創客/股票機/pico_i2c_lcd.py) 補齊 `backlight_on()` 與 `backlight_off()` 方法。
   - 修正 MicroPython 無原生 `str.ljust()` 導致畫面卡住的問題。
5. **靜態神殿 Landing Page (`render_landing_page`)**：
   - 開機連線後進入待命模式，顯示 `✦ GEEK  ORACLE ✦` 與 `⟐ [Press To Pray]`。
6. **打字機動態咒語詠唱 (`typewriter_print`)**：
   - 按下 GP14 觸發儀式，逐字緩慢印出 `Summoning Bull..` 與 `Aligning Cosmos.`。
   - 伴隨背光兩度神聖閃爍開光 (`holy_backlight_pulse`)。

## [v1.0] - 2026-11-12
### 主題：基礎版骨幹完成與雲端中繼發布
#### 完成內容：
1. **雲端中繼 API (Google Apps Script)**：
   - 撰寫 `google_apps_script.js`，透過 Google 試算表 `GOOGLEFINANCE("TPE:TAIEX")` 抓取大盤指數與漲跌資訊，轉為 JSON 輕量 REST API。
2. **雙 Wi-Fi 自動備援機制**：
   - 遵循多 SSID 優先權規範（手機熱點優先，家用 Wi-Fi 備援）。
3. **LCD1602 I2C 驅動整合**：
   - 實作自訂 5x8 點陣字元（▲ 漲、▼ 跌、Wi-Fi 圖標）。
   - 實作防閃爍與雙行格式化輸出。
4. **硬體按鍵支援**：
   - GP14 實體按鈕立即抓取與重整。
   - GP16 實體按鈕開關 LCD 背光省電模式。
5. **程式碼與文件建置**：
   - `main.py`、`stocks.py`、`config.py`、`pico_i2c_lcd.py`、`lcd_api.py`。
   - `readme.md`、`開發計劃.md`、`硬體配置.md`、`試算表配置與操作指南.md`。
