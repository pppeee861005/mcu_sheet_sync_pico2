# 股票機：Google 試算表結構與綁定指南

本文件說明如何建立與配置「**台股大盤指數監控試算表**」，供 Google Apps Script (GAS) 寫入最新行情歷史與提供 Pico 2 W 查詢。

---

## 一、 建立 Google 試算表步驟

1. 開啟 [Google 雲端硬碟](https://drive.google.com/) 或直接瀏覽 [Google Sheets](https://sheets.new) 建立一份空白試算表。
2. 將試算表命名為：`台股大盤監控機_歷史數據庫`。
3. 將下方工作表（Tab）重新命名為：`大盤歷史`（英文代號為 `TaiexHistory`）。

---

## 二、 工作表欄位格式設計 (`大盤歷史`)

請在第 1 列依序設定以下標題欄位：

| 欄位 (Col) | 標題名稱 | 說明 | 範例值 |
| :---: | :--- | :--- | :--- |
| **A** | **更新時間 (Timestamp)** | 寫入時的系統時間 | `2026-11-11 19:00:00` |
| **B** | **交易日期 (Date)** | 證交所公告交易日 (民國年) | `113/11/11` |
| **C** | **大盤指數 (Index)** | 發行量加權股價指數 | `23,522.53` |
| **D** | **漲跌點數 (Change)** | 當日漲跌點數 (帶正負號) | `+148.87` |
| **E** | **趨勢方向 (Direction)** | 漲/跌/平 (UP / DOWN / FLAT) | `UP` |
| **F** | **查詢來源 (Source)** | 請求來源標記 | `Pico_2_W` 或 `GAS_Timer` |

> **建議格式設定**：
> - 將 **C 欄** 與 **D 欄** 設定為數字格式或置中對齊。
> - 在 **D 欄** 設定條件式格式：
>   - 文字開頭為 `+` $\rightarrow$ 淺綠底紅字（台股漲紅）
>   - 文字開頭為 `-` $\rightarrow$ 淺紅底綠字（台股跌綠）

## 三、 Google 試算表專屬綁定 GAS 腳本 (Container-bound Script)

開啟該試算表，點選頂部功能表的 **「擴充功能 (Extensions)」 $\rightarrow$ 「Apps Script」**，將現有專案的 `google_apps_script.js` 貼入，或使用升級版自動記錄寫入函式：

```javascript
/**
 * 試算表綁定版 - 抓取大盤並同步記錄進試算表
 */
function doGet(e) {
  try {
    const stockData = fetchAndRecordTwseTaiex();
    return ContentService.createTextOutput(JSON.stringify(stockData))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function fetchAndRecordTwseTaiex() {
  const stockData = fetchTwseTaiex(); // 執行 TWSE FMTQIK 爬蟲
  
  // 取得當前試算表與工作表
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName("大盤歷史");
  if (!sheet) {
    sheet = ss.insertSheet("大盤歷史");
    sheet.appendRow(["更新時間", "交易日期", "大盤指數", "漲跌點數", "趨勢方向", "查詢來源"]);
  }
  
  // 檢查最後一列是否已經記錄過同一交易日，避免頻繁重複寫入
  const lastRow = sheet.getLastRow();
  let shouldAppend = true;
  if (lastRow > 1) {
    const lastDateRecorded = sheet.getRange(lastRow, 2).getValue();
    if (lastDateRecorded === stockData.date) {
      // 同一交易日已存在，僅更新該行最新時間與數據
      sheet.getRange(lastRow, 1).setValue(stockData.timestamp);
      sheet.getRange(lastRow, 3).setValue(stockData.index);
      sheet.getRange(lastRow, 4).setValue(stockData.change);
      sheet.getRange(lastRow, 5).setValue(stockData.direction);
      shouldAppend = false;
    }
  }
  
  if (shouldAppend) {
    sheet.appendRow([
      stockData.timestamp,
      stockData.date,
      stockData.index,
      stockData.change,
      stockData.direction,
      "Pico_2_W"
    ]);
  }
  
  return stockData;
}
```

## 四、 部署步驟

1. 點擊右上角「**部署**」 $\rightarrow$ 「**新增部署作業**」。
2. 齒輪圖示選擇「**網頁應用程式 (Web App)**」。
3. 說明填寫：`股票機大盤中繼 v1.0`。
4. **執行身分**：`我 (Your Google Account)`。
5. **誰可以存取**：**`所有人 (Anyone)`**（重要：不可選僅限自己，否則 Pico 2 W 會因為需要 OAuth 授權而失敗）。
6. 點擊部署後取得「**網頁應用程式網址**」，將網址中的 ID 填入 Pico 2 W 的 `config.py` 中的 `GAS_SCRIPT_ID`。
