# 股票機 v1.01 開發計劃：神諭降臨（神秘儀式感擴充）

## 1. 專案背景與設計動機
在 v1.0 基礎版中，股票機已完成多 Wi-Fi 自動連線、Google Apps Script (GAS) 即時台股指數 API 串接、自訂 LCD1602 漲跌符號與雙實體按鍵控制。
然而，直接跳轉數據缺乏極客靈魂。v1.01 版本的核心目標是**將金融指數的查詢過程昇華為一場「召喚股神 / 參透天機」的神秘儀式**。透過靜態 Landing Page 待命、打字機動態咒語詠唱、閃爍符文凝聚與緩慢莊嚴的跑馬燈，為硬體互動注入強烈的戲劇性與儀式感。

---

## 2. 核心功能架構與狀態機 (FSM)

系統生命週期分為四大狀態：

```
+-------------------------------------------------------------+
|                     1. BOOT & CONNECT                       |
|               (連線 Wi-Fi，載入自訂神聖點陣圖標)              |
+-------------------------------------------------------------+
                              │
                              ▼
+-------------------------------------------------------------+
|                  2. STATE_IDLE (Landing Page)               |
|      LCD 靜態神壇畫面: "* GEEK ORACLE *" / "[Press to Pray]" |
|                 等待 GP14 按鍵觸發召喚儀式                  |
+-------------------------------------------------------------+
                              │ (按鍵觸發 BTN_REFRESH GP14)
                              ▼
+-------------------------------------------------------------+
|                 3. STATE_INCANTATION (詠唱咒語)              |
|        打字機逐字緩慢打印神諭咒語 (Typewriter Effect)         |
|        背光神聖微閃 (Holy Flash)，向雲端中繼發起天機請求       |
+-------------------------------------------------------------+
                              │ (API 資料回傳成功)
                              ▼
+-------------------------------------------------------------+
|                  4. STATE_REVEAL (天機揭曉)                 |
|       第一行鎖定指數 / 第二行平滑緩慢跑馬燈 (Marquee)         |
|         循環播放開光訊息後，靜態停駐或按鍵返回 Landing Page  |
+-------------------------------------------------------------+
```

## 3. 視覺與互動詳細規格

### 3.1 LCD1602 自訂字元圖標擴充 (5x8 點陣)
- **0 號字元**：`ICON_UP` (▲ 漲勢神符)
- **1 號字元**：`ICON_DOWN` (▼ 跌勢神符)
- **2 號字元**：`ICON_ORACLE` (⟐ / 水晶球靈石圖標)
- **3 號字元**：`ICON_PRAY` (✦ 星光/神聖光芒)

### 3.2 靜態 Landing Page（神殿待命）
- **Line 1 (0,0)**: `* GEEK  ORACLE *` （置中，兩側帶有神聖星點）
- **Line 2 (0,1)**: `[Press to Pray]` （呼吸提示或靜態凝視）

### 3.3 動態咒語詠唱 (Incantation Animation)
- **特效演算法**：`lcd_typewriter(line, text, delay_ms=80)`
- **神秘咒文序列（英文羅馬化神諭）**：
  1. 第一幕：`Awakening Bulls...` -> 短暫停頓 0.6 秒
  2. 第二幕：`Reading Cosmos...` -> 伴隨背光一次神聖閃爍（Backlight pulse）
  3. 第三幕：`Oracle Speaks!` -> 天機降臨

### 3.4 緩慢跑馬燈天機展示 (Slow Marquee)
- **Line 1**：固定顯示大盤即時數字與符號，如 `TAIEX: 23522.5 ▲`
- **Line 2**：長文本慢速跑馬燈（每格滾動約 250ms ~ 300ms）：
  - `* THE PROPHECY * CHG: +148.87 (+0.63%) * MAY THE BULL BE WITH YOU *`

## 4. 硬體腳位規範（維持 mcu_sheet_sync_pico2 相容）
- **I2C SDA**：GP0 (Pin 1)
- **I2C SCL**：GP1 (Pin 2)
- **BTN_PRAY (召喚天機 / 刷新)**：GP14 (Pin 19，Pull-Up)
- **BTN_TOGGLE (瞑想模式 / 背光切換)**：GP16 (Pin 21，Pull-Up)
